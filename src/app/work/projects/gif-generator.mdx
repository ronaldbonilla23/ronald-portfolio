## Project Summary

When putting together case studies for Behance or Pinterest, designers face a recurring problem: showcasing long designs (landing pages) dynamically without losing quality. To solve this, I designed and built a React web app from scratch that automates the creation of vertical-scroll GIFs. The tool lets users upload mockups, adjust technical parameters, and download an optimized file in seconds — all through a minimalist, frictionless interface.

## Key Features (UX/UI & Front-End)

- **Real-Time Preview:** A clean interface that lets users see exactly how the GIF's scroll will behave before rendering it, eliminating the trial-and-error process.
- **Parametric Control:** Users have full control over the final output through dynamic adjustments to duration, frame rate (FPS), and aspect ratio.
- **Client-Side Processing:** The entire image-to-GIF conversion logic runs directly in the user's browser via JavaScript, guaranteeing full file privacy and eliminating backend server costs.
- **Tool-Oriented Design:** A UI/UX stripped of visual distractions, 100% focused on the task. The design guides the user step by step from uploading the JPG/PNG to the final download.

## Technologies Used

- **React:** Core application architecture and state management for sliders and configuration options.
- **Canvas API / Rendering Logic:** For manipulating the original image's pixels and generating the GIF's frames.
- **CSS / Tailwind:** Responsive layout, ensuring the tool works on both large monitors and laptops.

## Challenges & Learnings

The biggest technical challenge was optimizing app performance. Generating a GIF frame-by-frame in the browser can consume a lot of RAM and block JavaScript's main thread. I solved this by optimizing how frames are captured and processed through the Canvas, achieving the right balance between high visual quality and a file size optimized for social media.

## Result

An internal tool born from a personal design need that became a functional product. It shows the ability to spot pain points in the UX/UI workflow and solve them by building scalable software.
