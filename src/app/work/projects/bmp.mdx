## Project Summary

As part of the Front-End development team at the agency **Waytics**, I helped build the virtual certification platform for BPM SAS. The system is designed for thousands of users to train and recertify annually in food handling. The main challenge was building a smooth learning interface that combined multimedia consumption, progress tracking, and a strict assessment system for automatic certificate generation — all backed by a hybrid Laravel and Vue.js architecture.

## Key Front-End Development Features

- **Multimedia Learning Flows:** Integrated video players and document viewers (supplementary materials) into a clean UI designed to hold student attention and reduce drop-off rates.
- **Dynamic Assessment System:** Built the visual components for certification quizzes. The interface required immediate real-time feedback as users answered and submitted assessments to pass each module.
- **State & Progress Management:** Built visual indicators (progress bars, locked/unlocked module states) synced with the database to ensure users completed 100% of the content before the certificate download unlocked.

## Technical Architecture: Vue & Laravel Livewire

The project needed fast interactivity without burdening the client with a massive SPA (Single Page Application).

- **Laravel Livewire:** Used to handle asynchronous server communication reactively. This allowed heavy business logic (like validating assessment answers and generating PDFs) to run without page reloads, while writing less raw JavaScript.
- **Vue.js:** Implemented for highly interactive Front-End micro-components where Livewire fell short, ensuring smooth transitions and instant handling of user events.

## Challenges & Learnings

Working in an ecosystem that combines Livewire and Vue.js was a great Front-End architecture challenge. I learned to delegate technical responsibilities: using Vue for pure UI reactivity (UI state) and letting Livewire handle server state. Collaborating within the Waytics team also let me sharpen my workflows around version control and code review on medium-to-large-scale projects.

## Result

A robust, intuitive, failure-resistant e-learning platform. Users complete their recertification without technical frustration, consuming multimedia content and taking exams in an interface that responds instantly to their actions.
