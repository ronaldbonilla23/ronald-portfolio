## Project Summary

Ancore needed a complete digital overhaul. The goal was to turn its online presence into a lead-generation engine through a simple, modern, intuitive interface that matched the company's identity. I took on the hybrid role of designing the UX/UI and building the Front-End architecture in WordPress, making sure the visual design was perfectly aligned with a dynamic, SEO-optimized data structure.

![Ancore Before - Outdated Design](/images/projects/ancore/ancore-02.jpg)
<small>**Starting point (before the redesign):** Unfriendly, outdated design.</small>

## Key Design Features (UX/UI & CRO)

- **Color-Based Classification System:** To reduce cognitive load, I designed an information architecture where each service line is categorized by a specific color. The challenge was achieving this color differentiation while keeping a cohesive, elegant global aesthetic that didn't break Ancore's brand identity.
- **Conversion-Oriented Design (CRO):** Structured clean navigation flows and strategically placed CTAs to guide users toward conversion, eliminating leak points in the interface.
- **SEO-Optimized Layout:** The layout was conceptualized in Figma with web semantics in mind. Heading hierarchy (H1, H2, H3), content distribution, and perceived load speed were specifically designed to meet Google's Core Web Vitals metrics.

## Technical Architecture (Front-End & WordPress)

Beyond the visual layer, the real value of this project lies in its technical robustness under the hood:

- **100% Dynamic Front-End Development:** Eliminated any dependency on hardcoded content. Every piece of information rendered in the interface is dynamically pulled from the database.
- **Custom Post Types (CPT) & Custom Fields:** Architected the WordPress backend by creating custom post types for services and structuring data with custom fields (ACF). This lets the client update text, images, and colors for each service from a simple panel, with the Front-End adapting automatically without breaking the design.

## Challenges & Learnings

The biggest challenge was striking the right balance between a visually compelling design (with the multi-color system) and extremely clean code that loaded fast for SEO. I learned to structure my Front-End components so that styling (each service's colors) was dynamically injected through CSS variables fed directly from WordPress Custom Fields — bridging design and data logic seamlessly.

## Result

The result is a modern, intuitive, fast platform that not only captures user attention and drives lead conversion, but also gives Ancore a scalable, fully self-manageable technical infrastructure.
