## Project Summary

Makai Hostel needed a digital refresh that reflected its vibrant identity while improving direct-booking metrics. I led the creation of a design system from scratch and the restructuring of the user experience. The main goal was reducing cognitive friction and optimizing conversion, integrating AI-assisted workflows to speed up conceptualization and deliver a dev-ready product with ultra-fast load times.

## Key Features

- **Vibrant Design System:** Built a library of modular components in Figma, defining color, typography, and spacing tokens that convey the brand's energy without sacrificing accessibility.
- **Booking Engine Optimization (CRO):** Restructured the information architecture to minimize the clicks needed to complete a booking, always prioritizing the mobile view.
- **AI-Assisted Ideation:** Strategic use of AI tools for initial structural wireframing and refining persuasive copywriting, cutting down discovery-phase time.
- **Mobile-First Handoff:** Delivered pixel-perfect prototypes with strict CSS/Tailwind technical guidelines so the development team could implement ultra-fast interfaces — critical for travelers booking from their phones.

## Technologies Used

- **Figma:** High-fidelity prototyping, variables, and Auto Layout.
- **Generative AI Tools:** For copy optimization and rapid wireframing.
- **WPO Principles (Web Performance Optimization):** Applied from the UI design phase to keep assets lightweight.

## Challenges & Learnings

The biggest challenge was balancing a visually striking design (with immersive image galleries) with technical performance. I solved this by designing the galleries' visual treatment with lazy loading in mind from the UI concept stage — which taught me to align aesthetic decisions with the technical constraints of mobile networks.

## Result

The redesign delivered a much cleaner, more direct user flow. A meticulous technical handoff ensured the eventual implementation not only matched the approved design pixel-for-pixel, but performed with the smoothness today's mobile users expect — directly impacting conversion rate.
