## Resumen del Proyecto

Como parte de la transformación digital de Audifarma, lideré el diseño de la experiencia de usuario (UX) y la interfaz gráfica (UI) de su aplicación móvil oficial. El reto principal fue construir un producto capaz de atender a una base masiva de más de 15.000 usuarios activos recurrentes. Para lograr la coherencia entre plataformas, desarrollé desde cero el Sistema de Diseño completo y parametricé el prototipado interactivo respetando los lineamientos nativos tanto para Android (Material Design) como para iOS (Human Interface Guidelines).

## Características Clave

- **Sistema de Diseño Escalable**: Creación de una arquitectura de componentes UI en Figma, centralizando tokens de marca (colores, tipografía, sombreados) para garantizar que cualquier actualización visual se refleje automáticamente en todas las pantallas.
- **Prototipado Omnicanal**: Diseño y flujo interactivo de pantallas diferenciadas para iOS y Android, asegurando que gestos, navegaciones y áreas táctiles (Touch Targets) se sintieran 100% nativos para el usuario de cada sistema operativo.
- **Accesibilidad y UX Médica**: Optimización de la legibilidad, contraste y jerarquía de la información, considerando que una gran porción de la demografía de usuarios de farmacia incluye adultos mayores que requieren flujos de navegación sin fricciones.
- **Handoff para Desarrollo Móvil**: Entrega de documentación técnica y *assets* estructurados para facilitar la implementación por parte del equipo de ingeniería (preparado para ecosistemas como React Native o desarrollo nativo).

## Tecnologías Utilizadas

- **Figma**: Uso avanzado de *Variants*, *Component Properties* y *Auto Layout* para la construcción del UI Kit.
- **Patrones de Diseño Móvil**: Aplicación estricta de normativas de Apple y Google para garantizar la aprobación en las tiendas de aplicaciones (App Store y Google Play).

## Retos y Aprendizajes

El mayor reto fue manejar la complejidad de los flujos de salud (recetas médicas, autorizaciones, estado de medicamentos, turno virtual, PQRS y red de farmacias) en el espacio reducido de una pantalla móvil. Aprendí a simplificar procesos de múltiples pasos utilizando técnicas de revelación progresiva (*Progressive Disclosure*), mostrando al usuario solo la información necesaria en el momento exacto, lo que redujo drásticamente el abandono de procesos críticos.

## Resultado

La entrega de un Sistema de Diseño robusto y un prototipo de alta fidelidad eliminó la ambigüedad en la fase de desarrollo. El resultado es una aplicación que no solo refleja el peso corporativo y la confianza de Audifarma, sino que está técnicamente estructurada para escalar, soportar alto tráfico y evolucionar sin romper la coherencia visual.
