## Project Summary

As part of Audifarma's digital transformation, I led the UX and UI design of its official mobile app. The main challenge was building a product able to serve a massive base of 15,000+ recurring active users. To achieve cross-platform consistency, I built the complete Design System from scratch and parameterized the interactive prototyping while respecting native guidelines for both Android (Material Design) and iOS (Human Interface Guidelines).

## Key Features

- **Scalable Design System:** Built a UI component architecture in Figma, centralizing brand tokens (colors, typography, shadows) so any visual update automatically propagates across every screen.
- **Omnichannel Prototyping:** Designed distinct interactive flows for iOS and Android, ensuring gestures, navigation, and touch targets felt 100% native on each operating system.
- **Accessibility & Healthcare UX:** Optimized readability, contrast, and information hierarchy, accounting for the fact that a large share of pharmacy users are older adults who need frictionless navigation flows.
- **Handoff for Mobile Development:** Delivered structured technical documentation and assets to streamline implementation by the engineering team (ready for ecosystems like React Native or native development).

## Technologies Used

- **Figma:** Advanced use of Variants, Component Properties, and Auto Layout to build the UI Kit.
- **Mobile Design Patterns:** Strict application of Apple and Google guidelines to ensure app store approval (App Store and Google Play).

## Challenges & Learnings

The biggest challenge was handling the complexity of healthcare flows (prescriptions, authorizations, medication status, virtual queueing, complaints/PQRS, and pharmacy network) within the limited space of a mobile screen. I learned to simplify multi-step processes using Progressive Disclosure, showing users only the information they need at the exact right moment — which drastically reduced drop-off in critical flows.

## Result

Delivering a robust Design System and a high-fidelity prototype eliminated ambiguity during development. The result is an app that reflects Audifarma's corporate weight and trustworthiness while being technically structured to scale, handle high traffic, and evolve without breaking visual consistency.
